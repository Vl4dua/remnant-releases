## 🚀 Overview

**REMNANT** is a modern, standalone Windows desktop application designed to thoroughly eliminate software remnants, ghost registry entries, orphaned services, and disk waste that standard uninstallers leave behind.

Built on native **WinUI 3** and **.NET 9**, REMNANT runs completely self-contained with zero runtime dependencies.

---

## ✨ Key Features

* 🔍 **Ghost Hunt & Orphan Scanner**: Detects abandoned files, folders, scheduled tasks, and registry keys left by previously removed software.
* 🛡️ **Safe Vault & Backup**: Automatically compresses and backs up every trace before removal. Restore any file or registry entry with a single click at any time.
* 🧹 **Deep System Cleanup**: Safely cleans temporary files, application caches, crash dumps, and empties the Recycle Bin.
* 📊 **Disk Storage Analyzer**: Real-time visual categorization of drive space across Games, Applications, Media, Documents, and System data.
* 🔄 **Seamless Auto-Updates**: In-app one-click updates directly hosted from GitHub Releases with zero terminal prompts.
* 🌐 **Bilingual Support**: Full native support for both **English** and **Italian**.
